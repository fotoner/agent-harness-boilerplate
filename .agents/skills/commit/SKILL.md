# commit

커밋을 **초안 검수 게이트**와 **금지 패턴 자체 검증**을 거쳐 수행한다.
에이전트는 이 스킬의 절차를 거치지 않고 `git commit` 을 직접 실행하지 않는다
(CLAUDE.md "커밋·PR 게이트").

## 핵심 원칙

1. **초안 승인은 콘텐츠 승인이다**: 도구 실행 승인(권한 모드 / approval policy)은 커밋 메시지 초안에 대한 사용자 승인을 **대체하지 않는다**. 초안을 제시하고 명시적 텍스트 승인을 받은 뒤에만 커밋한다.
2. **파일 단위 staging**: `git add <구체 파일>`. `git add -A` / `git add .` 금지. 사용자가 승인하지 않은 파일을 끼워 넣지 않는다.
3. **자기완결 메시지**: 커밋 메시지는 외부 plan/spec 문서 없이 그 자체로 의미가 통해야 한다 (`docs/QUALITY_RULES.md` "커밋 메시지 self-contained 원칙"). 단, `docs/REQUIREMENTS.md` 에 매핑된 안정적인 요구사항 ID(예: `[D1.1]`)는 프로젝트의 추적 컨벤션이므로 허용된다 — 금지 대상은 휘발성 플랜 라벨이다.
4. **컨벤션 준수**: 커밋 타입·형식·AI attribution(`Co-Authored-By`) 여부는 `docs/CONVENTIONS.md` "커밋 메시지" 규칙을 따른다.

## 절차 (체크리스트)

1. **변경 검토 + 논리 단위 분할**
   - `git status` / `git diff` 로 변경 전체를 파악한다.
   - 서로 다른 의도의 변경이 섞여 있으면 분할 커밋을 제안한다. commit 단위는 의도·리스크·검증 게이트 기준이다 (`docs/CONVENTIONS.md` 브랜치 단위 판단 기준 참고).

2. **staging**
   - 커밋 대상 파일만 구체 경로로 `git add` 한다.
   - staged 목록(`git status`)을 확인하고 의도하지 않은 파일이 없는지 본다.

3. **메시지 초안 제시 → 승인 게이트**
   - 커밋 메시지 초안(제목 + 필요 시 본문)을 사용자에게 제시하고 승인을 기다린다.
   - 형식은 `docs/CONVENTIONS.md` "커밋 메시지" 규칙을 따른다.
   - **예외**: 사용자가 승인한 플랜에 **커밋 단위와 메시지 형식(템플릿/예시)이 함께 명시된** plan-실행 task 커밋은 이 게이트를 충족한 것으로 본다 (CLAUDE.md "커밋·PR 게이트"). 플랜에 메시지 형식이 없으면 예외 비적용. 이 경우에도 4단계 검증은 생략하지 않는다.

4. **금지 패턴 자체 검증 (커밋 직전)**
   - staged diff 와 메시지에서 프로젝트가 정의한 금지 패턴(`docs/QUALITY_RULES.md` "커밋 메시지 self-contained 원칙" 의 `{{BANNED_PATTERNS}}` 목록)이 0건임을 확인한다.
   - 검출되면 커밋하지 말고 정리 후 3단계부터 다시.

5. **pre-commit 훅 처리**
   - 훅이 이번 변경과 무관한 기존 에러로 실패하면 우회(`--no-verify` 등)할 수 있으나, **우회 사유와 잔존 에러 수를 커밋 메시지 또는 보고에 명기**한다.
   - 훅이 staged 파일을 수정(포매터 등)하면 diff 를 다시 확인한다.

6. **커밋 + 보고**
   - 커밋 실행 후 해시·제목을 1줄로 보고한다. push 는 별도 지시 또는 `pr` 스킬에서.

## 자주 하는 실수

| 실수 | 교정 |
|------|------|
| `git add -A` / `git add .` 로 일괄 staging | 구체 파일 단위로만. |
| 초안 제시 없이 바로 커밋 | 승인 게이트는 생략 불가 (플랜 명시 예외 제외). |
| 커밋 메시지에 휘발성 플랜 라벨(`Phase N`, `plan v2 task X`) | 의도만 서술. 금지 패턴은 grep 검증에서 차단. |
| 훅 우회 후 침묵 | 우회 사유 + 잔존 에러 수 명기. |

## Red Flags

- staged 목록에 사용자가 모르는 파일이 있다.
- 메시지 초안을 보여주기 전에 `git commit` 을 실행하려 한다.
- 금지 패턴 grep 을 "통과했을 것"으로 가정하고 생략하려 한다.
